# Brief for custom-page agents
Read: docs/admin-ui/CUSTOM-PAGES.md (decisions, route table, "How to build a page"), docs/admin-ui/PLAN.md (tokens --theme-*, classes .ui-*, components), src/admin/ui/index.ts, src/admin/lib (useSingleType, useCollection, useCollectionEntry, usePageForm), and the reference page src/admin/pages/PaginaEchipaPage.tsx (verified working end to end locally).
For each page you own:
1. Read the content type schema (src/api/<name>/content-types/*/schema.json and its components in src/components/**) and the custom field editors that edit it today (src/plugins/component-preview/admin/src/*Editor.tsx and components/*). Every field editable today must be editable on the new page, with the same hints/labels (Romanian, diacritics), validation and defaults.
2. Build the page in its own file src/admin/pages/<Name>Page.tsx (already created as a placeholder, route + sidebar already wired: do NOT edit menu.tsx, routes.ts, app.tsx, src/admin/ui/**, src/admin/lib/**; if you need a change there, stop and report it).
   Use only shared components: AdminPage, Window, PageHeader, Section / EditorCard / ObjectFieldCard, Field + Input/Textarea/Select/DateInput/DateRangeInput/TimeInput/NumberInput/TagsInput/SearchableSelect/SegmentedControl/Switch/Checkbox, RepeatableList (reorder / expandable / confirmDelete for deletes), GalleryGrid, ImagePicker (accept image/video), HelpTip, LinkOutCard, DataTable, Modal, Notice, EmptyState, Loading, SaveBar via usePageForm + saveState, adminToast.
   Repeatable components: always edit the loaded array (the save sends it whole).
3. No raw colours, no page CSS beyond small layout via existing .ui-* classes or inline flex/grid with --ui-space-* tokens.
4. Do not delete or change the plugin field editors (other pages may still use them); list which ones your page makes redundant.
Checks: `npx tsc --noEmit -p tsconfig.json` clean; `npx tsc --noEmit -p src/admin/tsconfig.json` no new errors (baseline 41); `node scripts/admin-ui-check.mjs` your files at 0. Never touch the local dev container (strapi_app) or ports 1337/5173. No push, no deploy, no subagents. One commit per page (conventional, no AI attribution). Tick your rows in docs/admin-ui/CUSTOM-PAGES.md.
Return only: status, commit SHAs, per page one line (fields covered / anything not covered and why), which plugin editors became redundant, one-line concerns.
