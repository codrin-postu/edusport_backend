## HTTP contracts

Shape as phase 5: success `200 { data: T }`; refusal `{ data: null, error: { status, name: 'ClubAdminError', message } }` (`refuseWith`), `message` the exact Romanian text. Dates `YYYY-MM-DD` (Europe/Bucharest), months `YYYY-MM`, ids are documentIds. A period is `from` and `to` inclusive. Files answer the bytes with `Content-Disposition: attachment; filename="<name>"`.

Common refusals: 400 "Cerere invalidă." (`PRESENCE_ERRORS.invalid`) for a malformed query or body; 400 "Perioada e prea lungă." for a period over 42 days on Prezență and coach routes, over 12 months on tables; 404 "Nu a fost găsit." (`PRESENCE_ERRORS.notFound`); 500 "Nu am putut încărca datele." for a failed read.
