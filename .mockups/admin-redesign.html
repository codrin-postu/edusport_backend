04

Panou de administrare EduSport personalizat: fezabilitate și machetă

Ce permite oficial Strapi 5 pentru pagina de start și meniul lateral, verificat în documentația Strapi. Pe scurt: pagina de start se personalizează prin widget-uri (app.widgets.register(), din 5.13), iar meniul lateral se augmentează cu app.addMenuLink(). Înlocuirea completă a paginii de start sau a meniului nu are un API oficial, dar repo-ul are deja precedent de injecție în DOM (vezi src/admin/app.tsx: MobileNav, SaveBar, tagare nav).

Recomandare

A + B combinate. Pentru pagina de start, folosește widget-uri oficiale (statistici, calendar, acțiuni) - stabil la upgrade. Pentru un panou EduSport bogat, adaugă o pagină de plugin dedicată și un addMenuLink către ea, opțional ca prima pagină după login. Evită abordarea C pentru pagina de start; păstrează injecția în DOM doar unde e deja necesară (mobil, save bar).

Machetă: pagină de start + bară laterală EduSport

Bara laterală grupează navigația pe limbajul școlii (Conținut site, Program și calendar, Sportivi și echipă), nu pe tipurile tehnice Strapi. Pagina de start deschide cu un salut, patru indicatori, calendarul apropiat și acțiuni rapide.

Cum recreăm asta

Două lucruri separate: (1) aspectul (pagina de start + meniul grupat) și (2) restricția de acces per cont. Nu au nevoie unul de altul; le combinăm.

1

Pagina de start EduSport

Carduri proprii pe homepage cu app.widgets.register() în src/admin/app.tsx (register): un widget pentru statistici, unul pentru "Următoarele evenimente", unul pentru "Acțiuni rapide". Fiecare widget e un component React care folosește @strapi/design-system și cheamă API-ul (ex. /api/calendar/occurrences) exact ca editorul actual. Oficial și stabil la upgrade.

2

Meniul lateral grupat

Bara laterală Strapi listează automat tipurile de conținut; nu se poate regrupa nativ. Pentru grupele EduSport (Conținut site / Program și calendar / Sportivi și echipă) adăugăm intrări cu app.addMenuLink(). Pentru un dashboard complet la o rută proprie, împachetăm pagina ca un plugin local de admin și o legăm cu addMenuLink; opțional o facem prima pagină după login printr-un redirect.

3

Cont restricționat (doar ce vrei tu)

RBAC este gratuit în Strapi 5. În Setări → Panou de administrare → Roluri: folosești rolul Editor sau Author (sau un rol nou), apoi bifezi doar tipurile de conținut la care contul are voie și, la nevoie, doar acțiunile permise (citire / creare / modificare / publicare), până la nivel de câmp. Content Manager ascunde automat din meniu ce rolul nu poate citi, deci utilizatorul vede exact ce îi permiți.

4

Punerea cap la cap

Creezi contul de antrenor cu rolul restricționat (pasul 3). La login vede meniul redus la tipurile permise, plus intrările tale din addMenuLink (pasul 2) și pagina de start cu widget-urile EduSport (pasul 1). Widget-urile respectă și ele permisiunile prin proprietatea permissions, deci un card se ascunde dacă rolul nu are acces.

De reținut la restricție: editarea permisiunilor pe rolurile Editor / Author este complet disponibilă gratuit. Rolul Super Admin nu poate fi modificat (are tot). Dacă ai nevoie de mai multe roluri restricționate diferite, verifică în ecranul Roluri dacă planul tău permite crearea de roluri noi; restricționarea rolurilor existente e oricum suficientă pentru un singur cont de antrenor.

Machete de prezentare pentru alegere. Nicio modificare nu a fost aplicată în sursa reală a panoului de administrare (punctele 1, 2, 4). Punctul 3 este o editare de o linie, documentată mai sus, neaplicată.
